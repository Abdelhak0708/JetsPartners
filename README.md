# Projet JetsPartners

## Description

J'ai refait entièrement la **page About** du site, en veillant à respecter toutes les bonnes pratiques de développement avec **Next.js**.

## Détails du travail effectué

- Refonte complète de la page About avec une attention particulière aux détails visuels et fonctionnels.  
- Utilisation des bonnes pratiques Next.js pour optimiser la performance, le rendu côté serveur (SSR) et le SEO.  
- Emploi de composants fonctionnels React avec hooks pour un code propre, clair et maintenable.  
- Gestion modulaire des styles pour assurer la réutilisabilité et la cohérence visuelle.  
- La page est désormais déployée et accessible en ligne.

Ce travail m’a permis de renforcer mes compétences en Next.js et de livrer une page About professionnelle et performante.
